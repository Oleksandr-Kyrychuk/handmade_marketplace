# Функціональні Вимоги до Order Service  
*Версія 1.5 — Актуальний стан проекту (20 листопада 2025)*

> **Мета**: Забезпечити повноцінне керування корзиною, замовленнями, елементами замовлень, платежами, доставкою та пов'язаними процесами в мікросервісній архітектурі Handmade Marketplace.  
> **Стан**: ≈81–84% реалізованих вимог (MVP — 100%, MVP+ — ~72%, Production-готовність — ~28%)  
> **Технології**: Django 5.1, DRF, JWT (через Authorization header + API Gateway), Celery + Redis, PostgreSQL (GIN index + search_vector), drf-spectacular, рольові дозволи, лог-фільтр чутливих даних.
