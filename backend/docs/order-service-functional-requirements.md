# Функціональні Вимоги до Order Service  
*Версія 1.6 — Актуальний стан проекту (14 січня 2026)*

> **Мета**: Забезпечити повноцінне керування корзиною, замовленнями, елементами замовлень, платежами, доставкою та пов'язаними процесами в мікросервісній архітектурі Handmade Marketplace.  
> **Стан**: ≈75–78% реалізованих вимог (MVP — 100%, MVP+ — ~68%, Production-готовність — ~25%)  
> **Технології**: Django 5.1+, DRF, JWT (через Authorization header + AuthMiddleware з User Service), Celery + Redis, PostgreSQL (GIN index + search_vector), drf-spectacular, рольові дозволи, лог-фільтр чутливих даних.
