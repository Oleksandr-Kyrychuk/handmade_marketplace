# Функціональні Вимоги до Order Service  
*Версія 1.0 — Enterprise-Ready Order Management Service*

> **Мета**: Забезпечити повноцінне керування замовленнями, елементами замовлень, платежами, доставкою та пов'язаними процесами в мікросервісній архітектурі Handmade Marketplace.  
> **Стан**: 0% реалізованих вимог, 100% — у плані розробки.  
> **Технології**: Django, DRF, JWT, Celery, Redis, PostgreSQL, Cloudinary, Swagger, OpenAPI, gRPC (планується).
