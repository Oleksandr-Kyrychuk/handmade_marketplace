# Функціональні Вимоги до User Service  
**Версія 1.4 — Актуальний стан на 14 січня 2026**  
**Статус: Production-Ready (≈ 78–82%)**  
*(критичні прогалини: відсутність тестів, кешування даних, захисту від брутфорсу, security headers)*

> **Мета** — Безпечне, масштабоване, асинхронне та enterprise-ready керування користувачами для Handmade Marketplace  
> **Технології** — Django 4+, DRF, SimpleJWT + token blacklist, Celery + Redis, PostgreSQL (users_schema), Cloudinary, drf-spectacular, django-filter, django-environ

### Легенда
- [x] — реалізовано та працює в продакшні  
- [~] — частково реалізовано (база є, але не завершено)  
- [ ] — не реалізовано / планується
