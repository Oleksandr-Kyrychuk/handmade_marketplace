# Use Case: Модерація продукту

| Поле | Значення |
|------|--------|
| **Назва** | Схвалити/відхилити продукт |
| **Актор** | Модератор |
| **Передумови** | Є продукти з `is_approved=False` |
| **Основний сценарій** | 1. Модератор відкриває `/moderation/products/` <br> 2. Бачить список <br> 3. Відкриває деталі <br> 4. Натискає "Схвалити" або "Відхилити" <br> 5. Система: <br> • Оновлює `is_approved` <br> • Celery: `send_moderation_notification` |
| **Альтернативи** | 4а. Відхилити → додати причину |
| **Результат** | Продукт оновлено, vendor отримав email |
| **API** | `PATCH /moderation/products/{id}/` |
| **Статус** | [x] MOD-02, MOD-03 |
