# Use Case: Увійти в систему

| Поле | Значення |
|------|--------|
| **Назва** | Логін через email + пароль |
| **Актор** | Користувач |
| **Основний сценарій** | 1. Вводить email + пароль <br> 2. API Gateway → `POST /auth/login/` <br> 3. User Service: <br> • Перевіряє `is_verified` <br> • Генерує JWT <br> 4. Повертає `access` + `refresh` |
| **Альтернативи** | 3а. Невірний пароль → `401` |
| **Результат** | Користувач авторизований |
| **API** | `POST /auth/login/` |
| **Статус** | [x] AUTH-01 |
