# Use Case: Health Check системи

| Поле | Значення                                                                                                                                   |
|------|--------------------------------------------------------------------------------------------------------------------------------------------|
| **Назва** | Перевірка здоров’я системи                                                                                                                 |
| **Актор** | Моніторинг (Prometheus)                                                                                                                    |
| **Тригер** | `GET /health`                                                                                                                              |
| **Основний сценарій** | 1. Запит до API Gateway <br> 2. Перевіряє: Redis, User Service, Product Service, схеми <br> 3. Успіх → `200` <br> 4. Помилка → `503` + деталі |
| **Результат** | Система моніториться                                                                                                                       |
| **API** | `GET /health`                                                                                                                              |
| **Статус** | ОК                                                                                                                                        |
