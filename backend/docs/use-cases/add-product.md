# Use Case: Додати новий продукт

| Поле | Значення |
|------|--------|
| **Назва** | Додати новий продукт |
| **Актор** | Vendor (авторизований, `user.id = vendor_id`) |
| **Передумови** | Користувач залогінений (JWT), має роль `user` |
| **Тригер** | Vendor натискає "Додати продукт" |
| **Основний сценарій** | 1. Vendor заповнює форму: назва, опис, ціна, категорія, фото (≤32MB) <br> 2. Натискає "Зберегти" <br> 3. API Gateway → `POST /products/` <br> 4. Product Service: <br> • Валідує дані <br> • Генерує `product_href` <br> • Зберігає `is_approved=False` <br> • Celery: `upload_image_to_cloudinary`, `moderate_content` <br> 5. Повертає `201 Created` |
| **Альтернативи** | 4а. Фото >32MB → `400` <br> 4б. Токсичний контент → авто-відхилення |
| **Винятки** | Cloudinary down → задача в черзі |
| **Результат** | Продукт створено, модерація запущена, email відправлено |
| **API** | `POST /products/` |
| **Статус** | [x] PROD-01, PROD-12, IMG-03 |
