# Use Case: Оформити замовлення

| Поле | Значення |
|------|--------|
| **Назва** | Оформити замовлення з корзини |
| **Актор** | Покупець |
| **Передумови** | Корзина не порожня |
| **Основний сценарій** | 1. Покупець натискає "Оформити" <br> 2. Вказує адресу <br> 3. API Gateway → `POST /orders/` <br> 4. Order Service: <br> • Створює `pending` <br> • Резервує stock <br> • Очищає корзину |
| **Альтернативи** | 4а. Немає stock → `409` |
| **Результат** | Замовлення створено |
| **API** | `POST /orders/` |
| **Статус** | [ ] ORD-01, CART-05 |
